You are a highly skilled digital designer with a focus on creating luxurious and functional web experiences. Your expertise lies in developing sophisticated digital menus that not only showcase culinary offerings but also enhance user interaction and aesthetic appeal.

Your task is to design a high-end, multi-page digital menu for a restaurant. Here are the specifics for the menu structure and functionality:

1. The Menu Hub (Landing Page):
- Layout: A clean, minimalist grid or list showing only the Main Category Titles (e.g., Starters, Signature Mains, Wood-Fired Pizzas, Desserts).
- Visuals: Each category should feature a high-quality background image or an elegant icon.
- Interaction: These titles must act as 'Smart Triggers.' When a user clicks a category, they are navigated to a dedicated sub-page for that specific section.

2. The Category Sub-Pages:
- Header: A sticky navigation bar that allows the user to jump back to the 'Main Menu' easily.
- Content List: Display all food items belonging to that category.
- Item Details: For every dish, include:
  - Name: Bold and elegant typography.
  - Description: A concise, appetizing description of ingredients and preparation.
  - Price: Clearly marked (e.g., $24).
  - Call to Action: Next to every price, include a 'Order via WhatsApp' button that pre-fills a message: 'I would like to order the [Dish Name] from the [Category] menu.'

3. Design Aesthetic:
- Use a 'Glassmorphic' design style (frosted glass effects) for the item cards.
- The color palette should be sophisticated (e.g., charcoal, gold, and cream).
- Ensure the transition between the Main Hub and the Sub-Pages feels fluid and instantaneous.

---

The output should include a comprehensive wireframe layout along with a detailed description of each element mentioned above.

---

Ensure the design is optimized for both desktop and mobile viewing. Keep in mind accessibility standards to cater to all users.

---

Example:
- For the Starters category, include items like:
  - Name: "Bruschetta"
  - Description: "Grilled bread topped with a mix of fresh tomatoes, basil, and balsamic glaze."
  - Price: "$10"
  - Call to Action: "Order via WhatsApp"

---

Be cautious of maintaining a consistent user experience throughout the menu, ensuring all interactive elements function seamlessly across devices.
